## Opportunity Valuation & Quantitative Model

### Win Probability Calculation
$$\text{Base Win Probability} = 0.50 \quad (6 \le \text{ncomments} \le 10)$$
$$\text{Age Penalty Multiplier} = 0.70 \quad (\text{ageHours} > 24)$$
$$\text{Effective Win Probability} = \min(0.95, \max(0.05, 0.50 \times 0.70)) = 0.350 \quad (35.0\%)$$

### Expected Value (EV)
$$\text{Tier Multiplier} = 1.0 \quad (\text{Tier } 2)$$
$$\text{Expected Value} = \text{round}(1000 \times 0.350 \times 1.0) = 350 \text{ sats}$$

## Architectural Deliverables

1. **Deterministic Parser (`parseRadarTSV`)**:
   - Supports 12-column Radar v2 schema with fallback for legacy 10-column schemas.
   - Converts numeric fields, calculates derived properties, and formats structured records.

2. **Opportunity Valuation Engine (`evaluateOpportunity`)**:
   - Evaluates competition tiers, age decay, sub-territory multipliers, and tag bonuses.
   - Computes win probability and mathematical expected value in satoshis.
   - Determines routing priority (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`) and actionable state transitions.

3. **Domain Content Generators**:
   - `evaluateNewsAnalysis`: Generates deep-dive submissions for ~news challenges ("Iceberg Ahead" framework covering surface events, structural undercurrents, impact vectors, and forward indicators).
   - `evaluateSelfPostOpportunity`: Synthesizes discussion hooks and community prompts for `SELF_POST_OPP` tagged items across sports, news, and philosophical inquiry.
   - `evaluateSportsPickEm`: Generates pick'em predictions and margin rationales across sports contests.
   - `evaluateLogicDiscussion`: Synthesizes deductive arguments and formal logic proofs.
   - `evaluateInquiryDiscussion`: Generates dialectical frameworks for AskSN questions.
   - `evaluateWeeklyCloseContest`: Generates structured price prediction entries.
   - `evaluateEconomicDiscussion`: Analyzes macroeconomic debt cycles and sovereign credit dynamics.

4. **Lifecycle State Machine (`SNBountyRegistry`)**:
   - Formal transition lifecycle: `DETECTED` -> `EVALUATED` -> `QUEUED` -> `CLAIMED` -> `IN_PROGRESS` -> `SUBMITTED` -> `PAID` (or `EXPIRED`/`REJECTED`).
   - File-backed atomic JSON persistence with summary analytics.

5. **CLI Interface & Reporting (`formatBountyReport`)**:
   - Markdown tabular output for terminal display.
   - Supports flags: `--tsv`, `--file`, `--filter`, `--save`, `--json`, `--news`, `--self-post`, `--sports`, `--logic`, `--inquiry`, `--contest`, `--econ`.

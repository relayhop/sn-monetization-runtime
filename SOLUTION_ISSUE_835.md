### Win Probability Calculation
$$\text{Base Win Probability} = 0.70 \quad (\text{ncomments} \le 5)$$
$$\text{Low Competition Multiplier} = 1.10 \quad (\text{tag: LOW\_COMP})$$

## Architectural Deliverables

1. **Deterministic Parser (`parseRadarTSV`)**:
   - Supports 12-column Radar v2 schema with fallback for legacy 10-column schemas.
   - Converts numeric fields, calculates derived properties, and formats structured records.

2. **Domain Analysis Generator (`evaluateNewsAnalysis`)**:
   - Generates comprehensive news iceberg teardowns focusing on structural transformations, underlying regulatory mechanics, and monetary implications.

3. **Dual Opportunity Synthesizer (`evaluateSelfPostOpportunity`)**:
   - Extracts conversational discussion angles and strategic thesis questions for `~news` self-post generation.

4. **Lifecycle State Machine (`SNBountyRegistry`)**:
   - Tracks operational status progression: `DETECTED` $\rightarrow$ `EVALUATED` $\rightarrow$ `CLAIMED` $\rightarrow$ `SUBMITTED` $\rightarrow$ `SETTLED` / `EXPIRED`.
   - Supports transactional updates, summary statistics, and JSON file persistence.

5. **Unified CLI & Automation Scripts**:
   - Supports `--row`, `--tsv`, `--file`, `--filter`, `--save`, `--json`, `--news`, and `--self-post` flags.
   - Default fallback directly loads Issue #835 telemetry.
